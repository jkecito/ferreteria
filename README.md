# Ferretería Web

Proyecto numero 2, continuacion de la entrega 1 donde se solicitaba la implementación del uso de la inteligencia artificial sabiendo que se tiene uso basico de paqueteria office y apenas saben lo que es la IA.

Para el proyecto se seleccionó una ferreteria, la idea es empezar haciendo uso de la IA para solicitar informacion del lugar, ubicacion, horario, algun anuncio asi como productos, costos. Para que puedan ser consultados en una pagina web.

## Objetivo

Crear una página web para una ferretería que permita:

- Mostrar un catálogo de productos.
- Actualizar productos mediante un agente chatbot cargados en el conocimiento del agente.
- Publicar la aplicación en Azure.
- Integrar un chatbot utilizando Azure AI Foundry.
